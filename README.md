# egressz — 本地出站授权侧车参考模型

纯 Go 标准库实现，无第三方依赖，全部组件只绑定/拨号回环地址（127.0.0.1），
不访问公网、不使用系统 DNS。

## 运行

```sh
go vet ./...
go test -count=1 ./...          # 全部单元测试 + 14 个参考模型场景
go test -count=1 -run TestAllScenarios -v ./cmd/reference
go build ./...
# 可执行入口（若沙箱允许输出二进制）：
go build -o reference ./cmd/reference && ./reference
```

## 包结构

| 包 | 职责 |
|---|---|
| `authz` | 授权身份元组、规范指纹、池键；HMAC-SHA256 令牌（绑定 ConnID） |
| `policy` | 不可变世代快照、规则求值、永久撤销墓碑、回环策略服务与 watch、回滚 |
| `mux` | 单连接帧多路复用；Hello ConnID 握手 + 每流 Auth 令牌校验/重定向/复位 |
| `pool` | 16 分片、按完整身份池键隔离的连接池；同地址不同身份不可借用 |
| `barrier` | 确定性命名屏障，复现撤销与新开流竞争（无 sleep 竞态） |
| `sidecar` | 解析与迟到丢弃、回环白名单拨号守卫、策略持有器、撤销边界、有界重试、重定向跳、本地 HTTP 代理监听 |
| `server` | 回环源站、授权测试代理（含重定向代理）、权威接收日志 DecisionLog |
| `client` | 文档同步测试客户端（经侧车出站，自身不拨号） |
| `testsupport` | 一键搭建完整回环拓扑、夹具、接收日志比对器 |
| `cmd/reference` | 可执行参考模型，枚举 14 个交错场景并打印 PASS/FAIL |

## 关键不变量

1. **身份决定信任**：身份 = 租户 + 策略世代 + 原始名称 + 解析来源 + 实际连接
   ConnID + 每跳重定向。池键排除 ConnID 但包含其余全部字段；同目标地址、不同
   身份落入不同桶，永不共享 mux 会话。令牌的 ConnID 必须等于握手 ConnID，
   否则服务端以 `conn_id_mismatch` 复位。
2. **撤销边界**：观察到墓碑后 `NewRequestAllowed` 永久拒绝新请求；已发送请求
   - abort 模式立即关流并关闭该身份的池会话；
   - drain 模式允许在可配置租约内完成，超时按读截止时间中止。
3. **故障不回退直连**：唯一拨号路径是 `GuardedDialer`，非白名单/非回环一律
   `ErrDirectDialBlocked`；无策略时空 bundle 判定为 deny（fail-closed）。
4. **迟到解析丢弃**：每次重试/重定向递增解析世代令牌，旧令牌的应答被丢弃。
5. **有界重试**：仅传输类错误重试且不超过 `MaxRetries`；授权拒绝不重试。
6. **回滚不恢复权限**：回滚以新世代重发旧规则，但墓碑跨世代保留，求值仍拒绝。

## 参考模型场景（cmd/reference）

1. 两租户同目标、不同身份的连接建立
2. 同身份的连接复用/借用
3. 同地址跨身份信任隔离
4. 重定向跳的逐跳重新授权（身份链扩展）
5. 代理策略拒绝且不重试
6. abort 撤销：新请求阻断、在途中止
7. drain 撤销：在途租约内完成、新请求阻断
8. drain 租约超时中止慢请求
9. 确定性屏障：撤销 vs 多路复用新开流竞争
10. 策略回滚不恢复已撤销权限
11. 传输故障有界重试后成功
12. 迟到解析应答丢弃
13. 故障关闭：拨号守卫拒绝直连/非回环
14. 两租户建立/借用/重定向/撤销/响应到达完整交错，以服务端接收日志比对判定

每个场景打印侧车预期、权威服务端 DecisionLog（含代理、判定、原因、ConnID、
指纹、跳数）以及逐条比对结果。
